# 🎓 CARI KELAS
> **Sistem Carian Kelas Ganti & Semakan Bilik Kosong Pintar**
> *by Muhammad Syafiq Haron*

Aplikasi web moden berprestasi tinggi untuk pensyarah dan pelajar Kolej Poly-Tech MARA (KPTM) Ipoh bagi menyemak jadual waktu, mencari slot kelas ganti tanpa pertembungan waktu, memeriksa ketersediaan makmal komputer/bilik kuliah fizikal, dan menjana memo kelas ganti secara pantas.

---

## ⚡ Ciri-Ciri Utama

1. **📅 Cari Kelas Ganti (Jadual Matriks Mingguan 5 Hari × 10 Waktu)**:
   - Pilih nama pensyarah dan kelas yang diajar.
   - Sistem memadankan jadual pensyarah dan kelas pelajar secara automatik.
   - Paparan jadual matriks melengkung (*curved pill matrix*) yang interaktif.
   - Pengesanan slot lapang (*✓ LAPANG*) dengan bilangan bilik fizikal sedia ada.
   - **1-Klik Salin Memo**: Format mesej siap dijana untuk dihantar terus ke WhatsApp atau memo rasmi pelajar.

2. **🏫 Cari Bilik Kosong (Waktu 1 hingga Waktu 10)**:
   - Semak ketersediaan makmal komputer dan bilik kuliah fizikal mengikut waktu dan hari.
   - Penapis khas untuk menapis bilik fizikal vs online dan mengecualikan bilik yang sudah ditempah.
   - Pilihan tempoh masa (1 Jam, 2 Jam, 3 Jam, Sesi Pagi, Sesi Petang, Sepanjang Hari).

3. **👨‍🏫 Jadual Pensyarah**:
   - Carian pantas jadual mengajar bagi 140+ pensyarah KPTM Ipoh mengikut hari dan waktu pembelajaran.
   - Pautan terus untuk mencari kelas ganti secara automatik mengikut pensyarah yang dipilih.

4. **👥 Jadual Kumpulan Kelas**:
   - Semakan jadual waktu penuh merentasi Waktu 1 hingga Waktu 10 bagi program DIA, DDM, DIM, DIT, DCW, dan lain-lain.

## 🛠️ Teknologi & Seni Bina

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router), React 18, TypeScript, Tailwind CSS
- **Deployment**: Standalone Native Engine sedia untuk [Netlify](https://www.netlify.com/) / [Vercel](https://vercel.com/)
- **Pangkalan Data Jadual**: Dataset terbina dengan integrasi data jadual EduPage KPTM Ipoh

---

## 🚀 Panduan Menjalankan Sistem Secara Lokal

### 1. Prasyarat
- Node.js (v18+) & npm

### 2. Pemasangan Pakej
```bash
npm install
```

### 3. Menjalankan Pelayan Pembangunan
```bash
npm run dev
```

Buka pelayar pada [http://localhost:3001](http://localhost:3001) untuk memulakan aplikasi.
